# US-04: Equipment return and optional damage note (5 points)

As a Staff member, I want to process a return and, when needed, add a damage note, so that a damaged
item leaves circulation.

**Page:** `/return/` (Staff and Admin).
**Code:** `inventory/views/return_item.py`, `LoanService.return_item` in `inventory/services.py`,
`templates/inventory/return.html`.

## What it does

- The asset tag alone finds the active loan; no borrower lookup is needed.
- Not damaged: closes the loan, sets Available, logs RETURN.
- Damaged: a non-empty note is required (form, service and a database check constraint); closes the loan,
  sets Repair, logs RETURN and DAMAGE_TO_REPAIR. Only an Admin can clear Repair (US-07).
