# US-02: Semester roster import (5 points)

As an Admin, I want to import the department's semester enrollment roster as a CSV file, so that every
student enrolled in a department course has a local account and students who are no longer enrolled
cannot sign in.

**Page:** `/accounts/roster/` (Admin only).
**Code:** `inventory/views/roster_import.py`, `AccountService.import_roster` in `inventory/services.py`,
`Profile` and `RosterImport` in `inventory/models.py`, `templates/inventory/roster_import.html`.
**Sample file:** `inventory/fixtures/mock_roster.csv`, columns `panther_id, username, display_name, email, phone`.

## What it does

- Validates every row before saving anything. Row numbers match the CSV line (header = row 1).
- New Panther ID: creates a Student account with no usable password and a one-time activation code.
- Known Panther ID: updates email, name, phone and term; reactivates the account if needed.
- Students missing from the file are deactivated, never deleted. Staff and Admin accounts are never deactivated.
- Shows created / updated / deactivated counts and the activation codes, once. Codes are stored only as hashes.

## Acceptance criteria and the tests that prove them

| # | Acceptance criterion | Test (`tests/test_roster_import.py`) |

| 6 | Students missing from the roster are deactivated; loan history kept | `test_missing_students_deactivated_history_kept`, `test_student_workers_never_deactivated` |
| 7 | The import shows created, updated and deactivated counts | `test_import_shows_counts` |
