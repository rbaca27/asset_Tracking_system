# US-07: Administrative inventory management and seed data (8 points)

As an Admin, I want to add, edit, and retire catalog records, set each item's loan-policy duration, and
load seeded demo data, so that the digital list matches the closet and checkout can compute a due time.

**Pages:** the Django admin site, `/admin/inventory/asset/` (Admin group only; the account also needs
`is_staff`, which only Admins get).
**Code:** `inventory/admin.py`, `LoanService.clear_repair`, `inventory/management/commands/seed_demo.py`,
`inventory/fixtures/assets.json`, `inventory/fixtures/mock_roster.csv`.

## What it does

- Access is checked by group, not per-model permissions. Delete is disabled: retire instead.
- Status is read-only in the form. It changes only through checkout, return and the
  **Clear Repair** action, so every change is logged (REPAIR_CLEARED).
- **Retire** skips items that are checked out (also enforced by `Asset.clean` and a database constraint).
- Loan duration takes `H:MM:SS` for hours or `D HH:MM:SS` for days, and must be longer than zero.
- `python manage.py seed_demo` loads 15 items, `admin1` and `staff1`, imports the mock roster, activates
  `zquin001`, and creates three demo loans (one overdue). Password for all: `demo-pass-123`.

## Demo, step by step

**Before you start** (see `docs/SETUP.md` for first-time setup). Make sure Postgres is running, then reset the demo data:

```bash
cd equipment-checkout
source .venv/bin/activate
export DB_PASSWORD=your-password
python manage.py flush --no-input
python manage.py seed_demo
python manage.py runserver
```

Open http://127.0.0.1:8000/. Every demo login uses the password `demo-pass-123`. Use a normal window and a
private window to be signed in as two people at once.

**How to sign in.** Click **Sign in** at the top right of any page, or go to http://127.0.0.1:8000/accounts/login/.
After `seed_demo`, these three logins work straight away (password `demo-pass-123` for all):

| Username | Role | What they see |
| --- | --- | --- |
| `admin1` | Admin | Everything: Inventory, Roster, Staff, plus all the desk pages |
| `staff1` | Staff | Checkout, Return, Overdue, Event log |
| `zquin001` | Student | My loans |

The other students (`mrive002`, `jchen003`, ...) have no password until they activate. Go to
http://127.0.0.1:8000/accounts/activate/ (also linked from the sign-in page), type the username and that student's
activation code (printed in the terminal by `seed_demo`), then choose a password. To switch users, click **Sign out**
at the top right, or use the private window.

If sign-in fails, check that you ran `seed_demo` after the last `flush` (flush deletes every account), that
the server is still running at `127.0.0.1:8000`, and that the password is all lowercase.

1. Seed data: the `seed_demo` command you just ran printed "Demo inventory loaded (15 items)" and the roster counts.
   The catalog shows 14 items (CAM-001 is retired), and `inventory/fixtures/mock_roster.csv` is the sample roster
   that the US-02 demo imports. *(AC 5)*
2. Sign in as `staff1` and go to `/admin/`. You get Django's admin sign-in page, not the inventory, because Staff have no
   admin access. As `zquin001`, it is the same. Sign out. *(AC 1)*
3. Sign in as `admin1` and click **Inventory**. Click **Add asset** and enter tag `PROJ-001`, type `Projector`,
   location `EIC Counter`, and loan duration `2 00:00:00` (2 days). Save it, and it appears in the catalog. Note
   that **Status** cannot be edited in the form. *(AC 2, 6)*
4. Open an existing item and set its loan duration to `0:00:00`. Saving is **refused** because the duration must be
   longer than zero. *(AC 2)*
5. Set `CHG-003`'s loan duration to `1 00:00:00` (1 day) and save. Click **Checkout** (an Admin can do desk work)
   and check out `CHG-003` to `zquin001`. The due time is **24 hours from now**. *(AC 6, 7)*
6. Back in **Inventory**, tick `HDMI-001` (in Repair), choose **Clear Repair (back to Available)**, and click Go.
   HDMI-001 is Available, and the event log shows **Repair cleared**. *(AC 4)*
7. Tick `HEAD-001`, choose **Retire (hide from the catalog, keep history)**, and click Go. It disappears from the catalog
   but stays in the admin list. Now try to retire `CHG-002`, which is checked out. It is **skipped** with a warning. *(AC 3)*
8. Notice there is no **Delete** action. Items are retired, never deleted, so loan history is kept. *(AC 3, 4)*

**Tests:** `pytest inventory/tests/test_admin_inventory.py inventory/tests/test_seed_data.py -v`
