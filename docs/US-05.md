# US-05: Student view of own loans (5 points)

As a Student, I want to sign in and see my active loans and due times, so that I know what I must
return and other students cannot see my record.

**Pages:** `/my-loans/` and `/my-loans/<loan id>/` (any signed-in user; shows only their own loans).
**Code:** `inventory/views/my_loans.py`, `templates/inventory/my_loans.html`, `loan_detail.html`.

## What it does

- Never reads an account ID from the URL or query string; every query is `borrower=request.user` (D-07).
- Another student's loan ID returns 404, so the page does not confirm the loan exists.
- Shows the student's own display name, mock Panther ID, email and phone, and an Overdue badge on late loans.
