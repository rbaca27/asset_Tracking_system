# US-05: Student view of own loans (5 points)

As a Student, I want to sign in and see my active loans and due times, so that I know what I must
return and other students cannot see my record.

**Pages:** `/my-loans/` and `/my-loans/<loan id>/` (any signed-in user; shows only their own loans).
**Code:** `inventory/views/my_loans.py`, `templates/inventory/my_loans.html`, `loan_detail.html`.

## What it does

- Never reads an account ID from the URL or query string; every query is `borrower=request.user` (D-07).
- Another student's loan ID returns 404, so the page does not confirm the loan exists.
- Shows the student's own display name, mock Panther ID, email and phone, and an Overdue badge on late loans.

## Demo, step by step

**Before you start** (see `docs/SETUP.md` for first-time setup). Make sure Postgres is running, then reset the demo data:

```bash
cd equipment-checkout
source .venv/bin/activate
export DB_PASSWORD=your-password
python manage.py flush --no-input
python manage.py seed_demo
python manage.py runserver
```

Open http://127.0.0.1:8000/. Every demo login uses the password `demo-pass-123`. Use a normal window and a
private window to be signed in as two people at once.

**How to sign in.** Click **Sign in** at the top right of any page, or go to http://127.0.0.1:8000/accounts/login/.
After `seed_demo`, these three logins work straight away (password `demo-pass-123` for all):

| Username | Role | What they see |
| --- | --- | --- |
| `admin1` | Admin | Everything: Inventory, Roster, Staff, plus all the desk pages |
| `staff1` | Staff | Checkout, Return, Overdue, Event log |
| `zquin001` | Student | My loans |

The other students (`mrive002`, `jchen003`, ...) have no password until they activate. Go to
http://127.0.0.1:8000/accounts/activate/ (also linked from the sign-in page), type the username and that student's
activation code (printed in the terminal by `seed_demo`), then choose a password. To switch users, click **Sign out**
at the top right, or use the private window.

If sign-in fails, check that you ran `seed_demo` after the last `flush` (flush deletes every account), that
the server is still running at `127.0.0.1:8000`, and that the password is all lowercase.

**Seeded state:** `zquin001` (Zelda) is activated and holds CHG-002. `mrive002` holds CALC-001, and `jchen003` holds LAP-001.

1. In the private window, sign in as `zquin001`. You land on **My loans**. Only **CHG-002** is listed, not
   CALC-001 or LAP-001. *(AC 1)*
2. The row shows the asset tag, type, checkout time and due time. *(AC 3)*
3. The top of the page shows Zelda's own name, mock Panther ID `6000001`, email and phone. *(AC 4)*
4. Click the CHG-002 loan to open its detail page, and note the number at the end of the URL
   (for example `/my-loans/1/`). Change it to another number, such as `2` or `3`, which are other students' loans.
   You get **404 Not Found**. The page does not even confirm that the loan exists. *(AC 2)*
5. Try `/my-loans/?user=mrive002` or `/my-loans/?type=Calculator`. You still see only Zelda's own loan.
   There is no page that lists who has which device type. Go to `/overdue/` and the page returns **403**. *(AC 2, 5)*
6. *(Optional)* In the main window, sign in as `staff1` and return `CHG-002`. Refresh Zelda's **My loans** and the
   list is empty. *(AC 1)*

**Tests:** `pytest inventory/tests/test_my_loans.py -v`
