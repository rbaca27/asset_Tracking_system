# US-09: Staff accounts and role assignment (1 point)

As an Admin, I want to create Staff accounts and add or remove the Staff role, so that only current desk
workers can record loans.

**Page:** `/accounts/staff/` (Admin only).
**Code:** `inventory/views/staff_roles.py`, `AccountService.create_staff` and `set_staff_role` in
`inventory/services.py`, `templates/inventory/staff_roles.html`.

## What it does

- Create a new desk account in the Staff group, or add the Staff role to an existing account (for example a
  student worker, who then holds both Student and Staff).
- Remove the Staff role with one button. Access is checked on every request, so removal takes effect at once.
- Staff accounts never get `is_staff`, so they cannot enter the Django admin site (D-05).

## Acceptance criteria and the tests that prove them

| # | Acceptance criterion | Test (`tests/test_staff_roles.py`) |
| --- | --- | --- |
| 1 | Only an Admin can create a Staff account or change groups | `test_only_admin_creates_staff_or_changes_groups`, `test_admin_creates_staff_account`, `test_duplicate_username_refused` |
| 2 | A user added to Staff can open checkout, return and overdue | `test_added_staff_opens_desk_pages` |
| 3 | A user removed from Staff gets 403 on those pages | `test_removed_staff_gets_403` |
| 4 | A student worker can be in both Student and Staff | `test_student_worker_holds_both_groups` |

Access to every Staff and Admin page by every role is also checked in `tests/test_access.py`.
